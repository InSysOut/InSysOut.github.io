Privacy Policy

InSysOut ANPR Event Viewer · Effective Date: July 2026

InSysOut ANPR Event Viewer is a developer and integration tool for viewing ANPR/LPR event payloads, vehicle images, plate crops, raw payloads, and related event metadata.

Data Collection

The app does not collect, transmit, sell, or share personal data with InSysOut or third parties.

Imported Files

Users may import ANPR event files from local device storage or supported file providers through the operating system file picker. Imported files may include JSON, XML, CSV, SQL, Protobuf, vehicle images, plate images, timestamps, camera metadata, location text, and other event fields.

Imported files are processed locally on the device for display and review. The app does not upload imported files to InSysOut servers.

Google Drive and File Providers

The app does not include direct Google Drive account integration. Users may access Google Drive files only through the standard operating system file picker if Google Drive is installed and enabled on the device.

Photos, Camera, and Location Permissions

The app may include permission descriptions for photo library, camera, or location access because operating system libraries or file import plugins can reference these protected APIs.

The app uses these permissions only when the user chooses to import, capture, attach, or review ANPR event files, vehicle images, plate images, or related event context.

The app does not continuously access the camera, photo library, or location in the background.

In-App Purchases

The app may offer a Pro unlock through Apple In-App Purchase. Purchase processing is handled by Apple. InSysOut does not receive or store full payment card information.

Children

This app is intended for professional, developer, operational, and integration use. It is not directed to children.

Data Sharing

The app does not sell or share user data.
